«Приложение повреждено»

После загрузки из браузера macOS блокирует запуск. Выполните в Терминале:

xattr -cr ~/Downloads/Magnific\ QA\ Desktop\ Agent.app
open ~/Downloads/Magnific\ QA\ Desktop\ Agent.app

Или: правый клик по приложению → Открыть → Открыть.

macOS Catalina

  • Только сборка macOS (Intel) — mac-x64.zip
  • Установите Google Chrome
